# Drop — Web App

A real, working web app (not a mockup): live AI request parsing and a
persistent watchlist, running client-side. No backend, no real retailer
connections, no real payments — those are explicitly labeled wherever
they're simulated in the UI.

Deploy as-is: `index.html` is self-contained and sits at the repo root,
so Vercel/Netlify/GitHub Pages need no configuration.
